# E-team のブランド

## ロゴ

- ロゴはワードマーク版（横長）。ヘッダーの高さは最小 56px
- 共通の `<BrandHeader />` を使う。インラインで `<img>` を直接書かない

## ブランドカラー（毎回ロゴから読み取らないこと）

`E-team AI公式サイト/public/logo-mark.png` の実測値。512px の PNG から画素を数えて確定した。

```
グラデーション（左下→右上）
  #00B4EA  →  #2DD4CF  →  #53EFB8
   シアン      ターコイズ    ミント

地      #FBFBF7   ほんのり暖色寄りのオフホワイト
文字    #0F172A   ほぼ黒に近い濃紺
```

CSS で使う場合：

```css
background: linear-gradient(135deg, #00B4EA 0%, #2DD4CF 50%, #53EFB8 100%);
```

- ロゴマークは**青→緑の一方向グラデーション**。単色で使うならターコイズ `#2DD4CF`
- 白背景に置くのが基本。濃色地に置く場合はロゴ側を白抜きにする
- 公式サイトの各セクションには別のグラデーション（暖色・緑系など）があるが、**それらはセクション装飾でブランドカラーではない**。混同しない
