# UI の決まり

## 「AI が作った見た目」の定番を使わない

AI でコーディングした経験のある人には一瞬で見抜かれるため、恒久的に禁止。

### 絶対に使わない

- **カードの上辺にカラーバー（アクセントバー）を載せる形**。`border-top: 3px solid <color>` も、`::before` で上辺に敷くグラデーションも同じ。一切禁止
- 白い角丸カードを3カラムで等間隔に並べただけのセクション
- グラデーションの円形アイコンチップ（丸背景＋中央にアイコン）
- 中央寄せ見出し＋中央寄せリード文＋カード3枚の定型レイアウト
- 絵文字アイコン

### 代わりに使う

- 罫線（hairline）と余白で区切る
- タイポグラフィの階層（大きい番号・ウェイト差・字間）で差をつける
- 実素材（写真・3D レンダリング）をレイアウトの主役にする
- ボタンだと伝えたいときは、面の明度差・影の強さ・明示的なラベル（例「詳しく見る」＋矢印）で伝える

### 作る前のチェック

「このパターンは生成 AI のテンプレで見たことがあるか？」を自問する。Yes なら別の手を考える。

## アイコン

- 絵文字アイコンは絶対に使わない。Lucide React（または Heroicons など）の SVG を使う

## 表示する情報

- 「残り99999パック」のような内部の管理値をユーザーに見せない
- UI 要素を足すときは「この情報はユーザーが何の判断に使うか？」を自問する。答えがなければ表示しない
