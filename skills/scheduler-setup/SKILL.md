# 定期実行の設定

## 設定内容は全項目をチェックリストで出す

- URL
- method
- headers（認証ヘッダーなど）
- タイムゾーン
- 実行間隔
- レスポンスの保存（ログ）

## 設定したら

- 1回手動で実行し、**実データで**結果を確かめる（200 OK が返るだけでは不十分）
- 課金のある処理（AI API など）を定期実行にするなら、作る前に月額の見込みを出して確認を取る（CLAUDE.md の「お金」）

## エンドポイント側

- SPA の POST 専用エンドポイントには、GET に 405 を返すガードを入れる
- cron 用のエンドポイントと管理画面の UI は分ける
